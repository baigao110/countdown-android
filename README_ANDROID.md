# 倒计时（安卓版）—— CountdownAndroid

把桌面版 Win11 倒计时工具移植到安卓平台，原生 Kotlin 实现，支持**后台悬浮窗动态倒计时**与**归零自定义提示音**。

### v1.0.1 更新（本次修复）

- **修复悬浮窗切换显示模式无效 / 报错退出**：原逻辑在悬浮窗内部持有旧数据对象，点按切模式后每秒刷新又把旧模式覆盖回去（看起来没变），且拖动时在非附加窗口上调用 `updateViewLayout` 会抛异常直接崩进程。现改为点按切模式时实时写入数据并 `setMode` 立即重绘，所有窗口操作均加了 `isAttachedToWindow` 保护与异常兜底，任何一次触摸都不会再导致进程崩溃。
- **新增悬浮窗抽屉功能**：点右上角「菜单」滑出抽屉，内含目标时间、备注、上一/下一模式、编辑、隐藏；再点「收起」收回。抽屉打开时点空白处不再误切模式。编辑后悬浮窗自动增量刷新（保留位置与抽屉状态，不闪烁）。
- 抽屉里的「编辑」会跳转到编辑页，保存后后台服务自动同步该悬浮窗。

### v1.0.2 更新（本次）

- **修复悬浮窗修改倒计时名称/内容无效**：`AddEditActivity` 保存时从磁盘重新加载了一份列表，却把改动写到了 `onCreate` 里另一份旧列表的副本上，导致磁盘数据没被更新、悬浮窗刷新后仍是旧名字。现改为「修改即将保存的那份列表里的同一个对象」，改名/改时间/改颜色/改模式/改备注全部即时生效并落盘。
- **新增透明度调节**：悬浮窗抽屉内新增「透明度」滑块，拖动即可实时调节窗体透明度（20%–100%，松手后自动保存），下次启动仍保留。
- **新增收缩/放开**：右上角「收」按钮可将悬浮窗收缩为只显示标题的小条（点小条即「放开」恢复）；收缩状态随数据保存，重启后保留。
- **备注显示到悬浮窗主体**：悬浮窗「显示模式」上方新增备注行（与桌面版一致），无需打开抽屉即可看到备注内容；收缩时自动隐藏。

### v1.0.3 更新（本次修复）

- **修复「启动悬浮窗」按钮导致程序闪退**：原 `AndroidManifest.xml` 把 `PROPERTY_SPECIAL_USE_FGS_SUBTYPE` 属性放在了 `<application>` 下，而 Android 14 要求它必须是 `<service>` 的子元素；否则 `startForegroundService` 会抛 `MissingForegroundServiceTypeException` 使应用崩溃。现已将该属性移入 `<service>` 内，启动悬浮窗不再崩溃。
- **修复隐藏后主界面按钮不翻转**：悬浮窗是覆盖层、不会触发 MainActivity 的 `onResume`，导致列表按钮停留在「隐藏」。现由服务在可见性变化时发送 `DATA_CHANGED` 本地广播，MainActivity 注册接收器实时刷新列表，隐藏后按钮立即变为「显示」、显示后变为「隐藏」。
- **修复悬浮窗位置不保存 / 再显示位置错乱**：`Countdown` 新增 `posX`/`posY` 字段，`CountdownStore` 同步读写。隐藏时服务读取悬浮窗当前位置并落盘；拖动结束时也实时保存；再次「显示」时按保存位置还原（并在越界时自动拉回屏幕内）。

### v1.0.0 更新（本次基线）

- **主界面实时倒计时**：列表每条倒计时下方新增一行动态剩余时间，每秒自动刷新（颜色与标题一致，文本格式与悬浮窗完全一致），无需启动悬浮窗也能在主界面看到正在跳动的倒计时。
- 应用名与桌面图标统一为「倒计时」，主界面标题同步更新为「倒计时」。
- 本版为重新基线化的 1.0.0，已包含此前 v1.0.1~v1.0.3 的全部修复（悬浮窗切模式、改名生效、透明度/收缩、启动闪退、隐藏后按钮翻转、位置保存还原）以及启动加固（无可见倒计时时只提示、不启动空服务）。

### v1.0.0 调整（本次）

- **提示音改为「手机铃声」选择器**：不再用文件选择器挑音频文件，而是调用系统 `RingtoneManager` 铃声选择器，直接列出手机铃声 / 通知音作为倒计时提示音选项；选「默认」即使用内置三声 beep，无需任何音频文件。
- **主界面移除「启动悬浮窗 / 停止悬浮窗」按钮**：改为全自动管理——存在「显示」中的倒计时且已授权时，自动拉起前台服务；全部隐藏时自动停止服务并关闭常驻通知。悬浮窗由各条目的「显示 / 隐藏」状态独立控制。
- **首次使用自动引导开启悬浮窗权限**：当存在「显示」中的倒计时但缺少「显示在其他应用上层」权限时，主界面自动弹出引导对话框，点「去设置」跳转系统授权页，返回后自动显示悬浮窗，无需再手动点按钮。
- **悬浮窗与主界面显示模式双向同步**：悬浮窗内切换显示模式后，服务会广播 `ACTION_DATA_CHANGED`，主界面列表实时刷新（显示模式名 + 剩余时间文本随之更新）；反过来在主界面编辑里改模式后也会即时同步到悬浮窗。两者始终一致。
- **提示音选择后回显铃声名称**：选择系统铃声后，按钮显示具体铃声名（如「已选择：来电铃声（点击更换）」），选「默认」则显示「使用默认提示音（点击选择）」，不再只显示通用文案。
- **主界面列表项滑动操作 + 长按拖动排序**：列表项「编辑 / 提示音 / 删除」三个按钮改为**从右往左滑动**该条目即可露出（前景左移、底部按钮呈现）；**从左往右滑动**、或点一下主内容区，即可收回恢复原样；**按住条目不放**（约 0.35 秒）进入拖动状态，拖动到目标位置松手即完成排序，拖动时原条目**轮廓虚化**（半透明 + 灰色描边），并有一个跟随手指的“幽灵”副本指示落点，顺序自动保存。**已修复**此前长按拖动会“错误退出”的问题：松手排序不再于触摸派发过程中改动视图树（改到下一帧重建列表），截图改用 Canvas 绘制而非弃用的 `buildDrawingCache`，任何一次触摸都不会再导致进程崩溃。版本仍为 v1.0.0。

## 二、权限说明

| 权限 | 用途 | 授予方式 |
|---|---|---|
| `SYSTEM_ALERT_WINDOW` | 在其他应用上层显示悬浮窗 | **需手动授予**：首次使用（有可见倒计时时）应用自动弹窗引导跳转系统设置页开启，返回后自动显示悬浮窗 |
| `FOREGROUND_SERVICE` / `..._SPECIAL_USE` | 后台保活常驻服务 | 安装即授予 |
| `POST_NOTIFICATIONS` | 显示常驻通知与归零通知 | Android 13+ 首次启动弹窗申请 |
| `RECEIVE_BOOT_COMPLETED` | 开机自动恢复悬浮窗 | 安装即授予 |
| `WAKE_LOCK` | 防止息屏后计时停滞 | 安装即授予 |

**必须手动开启悬浮窗权限**，否则悬浮框无法显示（服务仍会在后台运行并计时/响铃）。

## 三、如何编译 APK

### 方式 A：Android Studio（推荐，最简单）

1. 安装 [Android Studio](https://developer.android.com/studio)（含 Android SDK，建议 Gradle 8.2 / JDK 17，AS 已自带）。

5. 编译完成后点击提示中的 `locate`，或到
   `app\build\outputs\apk\debug\app-debug.apk` 取包，安装到手机即可。

## 四、使用说明

1. **安装并打开**，授予通知权限。
2. 点右下角 **`+`** 添加倒计时：填名称、选日期时间、挑颜色、选显示模式、写备注。
3. 若某条倒计时处于「显示」状态但还没给悬浮窗权限，主界面会自动弹出引导框，点「去设置」跳转系统授权页开启「显示在其他应用上层」，返回后悬浮窗自动出现（无需手动点启动按钮）。
4. 悬浮窗出现后：
   - **拖动** → 移动位置
   - **单击** → 循环切换显示模式
   - **右上角「菜单」** → 滑出抽屉：目标时间、透明度滑块、上一/下一模式、编辑、隐藏
   - **右上角「收/开」** → 收缩为小条 / 放开恢复
   - **右上角 ×** → 隐藏该倒计时悬浮窗
   - **备注**显示在「显示模式」上方（有备注时）
5. **设置归零提示音**：列表项点 **「提示音」** → 在系统铃声选择器中挑选手机铃声 / 通知音（无合适铃声可选「默认」，即内置 beep）。
   - 不设置则使用内置的默认提示音（三声合成 beep，无需音频文件）。
   - 归零时除播放提示音外，还会发送一条「倒计时归零」通知。
6. **主界面切换显示模式**：列表项的「模式」按钮可一键循环切换该倒计时的显示模式（模式名与剩余时间文本立即更新）；若该倒计时悬浮窗正在显示，会自动同步切换，二者始终一致。
7. **主界面滑动 / 拖动**：列表项**从右往左滑动**露出「编辑 / 提示音 / 删除」按钮，**从左往右滑动**（或点一下主内容区）收回；**按住条目不放**（约 0.35 秒）进入拖动，移动到目标位置松手即完成排序（拖动时原条目轮廓虚化，并有跟随手指的副本指示落点），新顺序自动保存。

## 六、实现要点 / 已知限制

- **悬浮窗**使用 `TYPE_APPLICATION_OVERLAY`（Android 8.0+ 唯一合法方式），依赖前台 Service 保活；Android 14+ 需要 `foregroundServiceType`，已声明为 `specialUse` 并附带 `PROPERTY_SPECIAL_USE_FGS_SUBTYPE` 说明。
- **计时精度**：服务内每 1 秒用 Handler 刷新一次，息屏/后台仍按系统时间计算剩余量（不会因掉帧走偏）。
- **提示音**：采用系统 `RingtoneManager` 铃声选择器，返回手机铃声 / 通知音的 content URI，由 `MediaPlayer` 播放（无需自带音频文件）；未选择（默认）则仍用 `AudioTrack` 实时合成三声 beep。若所选铃声不可用会自动回退到默认 beep。
- **默认提示音**由 `AudioTrack` 实时合成（880Hz 三声短响），因此工程内不含任何二进制音频资源。
- **minSdk 26**（Android 8.0）：低于 8.0 的设备无法安装；这是悬浮窗与自适应图标的最低要求。
- 部分国产 ROM（小米 MIUI、华为 EMUI、OPPO/ vivo 等）默认禁止后台自启动与悬浮窗，需要在系统「应用管理 → 权限 / 自启动 / 悬浮窗」中手动放行并加入后台保护名单，否则开机恢复与后台保活可能失效。
